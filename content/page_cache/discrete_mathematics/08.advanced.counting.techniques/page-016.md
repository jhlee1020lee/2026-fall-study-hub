  Divide-and-Conquer Algorithmic Paradigm
• Definition: A divide-and-conquer algorithm works by first dividing a problem into one or
  more instances of the same problem of smaller size and then conquering the problem using
  the solutions of the smaller problems to find a solution of the original problem.

• Examples
  – Binary search, covered in Chapters 3 and 5: It works by comparing the element to be located to the
   middle element. The original list is then split into two lists and the search continues recursively in
   the appropriate sublist
  – Merge sort, covered in Chapter 5: A list is split into two approximately equal sized sublists, each
   recursively sorted by merge sort. Sorting is done by successively merging pairs of lists.
