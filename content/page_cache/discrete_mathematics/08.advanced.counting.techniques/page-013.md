 Linear Nonhomogeneous Recurrence Relations
• Definition: A linear nonhomogeneous recurrence relation with constant coefficients is a
  recurrence relation of the form: an = c1an−1 + c2an−2 + ... + ck an−k + F(n) where c1, c2, ….,ck
  are real numbers with ck ≠ 0, and F(n) is a function not identically zero depending only on
  n. The recurrence relation an = c1an−1 + c2an−2 + ... + ck an−k is called the associated
  homogeneous recurrence relation.

• Examples
  – 𝑎𝑛 = 𝑎𝑛−1 + 2𝑛
  – 𝑎𝑛 = 𝑎𝑛−1 + 𝑎𝑛−2 + 𝑛2 + 𝑛 + 1
  – 𝑎𝑛 = 3𝑎𝑛−1 + 𝑛3𝑛
