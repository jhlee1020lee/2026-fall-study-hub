Complexity of Problems
• Class NP-Complete (NPC): If a problem is both in NP and NP-hard
  – The set of “hardest” problems in NP


• Consider the decision version of the Traveling Salesman Problem:
                                   Is there a tour with total distance ≤ K?
• This problem is NP-complete: a solution can be checked in a polynomial time.

               Class              Type of problems
               P                  decision problems solvable in polynomial time
               NP                 decision problems verifiable in polynomial time
               NP-Complete        hardest decision problems in NP
                                  at least as hard as NP problems (may not be decision
               NP-Hard
                                  problems)
