Combinations of Functions
• If f1 (x) = O(g1(x)) and f2 (x) = O(g2(x)) then
                   ( f1 + f2 )(x) = O(max{|g1(x)|,|g2(x)|}).

• If f1 (x) and f2 (x) are both O(g(x)), then
                    ( f1 + f2 )(x) = O(g(x)).

• If f1 (x) = O(g1(x)) and f2 (x) = O(g2(x)) then
                   ( f1 f2 )(x) = O(g1(x)g2(x)).
