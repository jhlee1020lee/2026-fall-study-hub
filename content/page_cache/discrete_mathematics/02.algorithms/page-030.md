Big-O Notation

• Def: Let f and g be functions from the set of
  integers or the set of real numbers to the set of
  real numbers. We say that f(x) = O(g(x)) if there
  are constants C and k such that
     |f(x)| ≤ C |g(x)|
 whenever x > k.

  – This is read as “f(x) is big-O of g(x)” or
                 “g asymptotically dominates f.”
  – The constants C and k are called witnesses to the
   relationship f(x) is O(g(x)).
