The Complexity of Algorithms
• In this course, we focus on time complexity.

• We will measure time complexity in terms of the number of operations an algorithm
  uses and we will use big-O and big-Theta notation to estimate the time complexity.

• We can use this analysis to see whether it is practical to use this algorithm to solve
  problems with input of a particular size. We can also compare the efficiency of
  different algorithms for solving the same problem.

• We ignore implementation details (including the data structures used and both the
  hardware and software platforms) because it is extremely complicated to consider
  them.
