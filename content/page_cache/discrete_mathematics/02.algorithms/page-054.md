Complexity of Problems
• Class NP: contains all decisional problems that solution can be checked in a polynomial time.
  – Informally: A problem is in NP if:
                If someone gives you a solution, you can verify it quickly.
  – Example: Example: Sudoku
     Question: Does this Sudoku puzzle have a valid solution?
     If someone gives you a completed board, you can check quickly:
     • each row valid
     • each column valid
     • each box valid
     Checking takes polynomial time.
