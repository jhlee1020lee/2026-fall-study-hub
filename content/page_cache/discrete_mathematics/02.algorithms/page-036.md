The Complexity of Algorithms
• Given an algorithm, how efficient is this algorithm for solving a problem given input of
  a particular size? To answer this question, we ask:
  – How much time does this algorithm use to solve a problem?
  – How much computer memory does this algorithm use to solve a problem?


• When we analyze the time the algorithm uses to solve the problem given input of a
  particular size, we are studying the time complexity of the algorithm.

• When we analyze the computer memory the algorithm uses to solve the problem
  given input of a particular size, we are studying the space complexity of the algorithm.
