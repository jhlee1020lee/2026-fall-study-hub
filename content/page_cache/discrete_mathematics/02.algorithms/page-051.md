Complexity of Problems
• In computational complexity theory, a decision problem is a computational problem that
  can be posed as a yes–no question of the input values.
• Class P: contains all decisional problems that can be solved (by a deterministic Turing
  machine) in a polynomial time.
• Class NP: a solution can be checked in a polynomial time.
• Class NP Hard: “at least as hard as the hardest problems in NP”
• Class NP-Complete (NPC): If a problem is both in NP and NP-hard
  – The set of “hardest” problems in NP
  – If a polynomial time algorithm for any NPC problem is found, then that algorithm can be used to
   obtain a polynomial time algorithm for an arbitrary NP problem.
