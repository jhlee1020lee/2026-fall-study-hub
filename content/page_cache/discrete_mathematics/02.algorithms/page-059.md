Complexity of Problems
• Consider the decision version of the Traveling Salesman Problem:
• Is there a tour with total distance ≤ K?
• This problem is NP-complete. If someone discovered a polynomial algorithm for
  this problem:
                                   𝑂 𝑛3 or 𝑂 𝑛10
 then immediately:
 → NP-complete ∈ P
 → NP ⊆ P
 → P = NP
• This would solve the P vs NP problem.
