Complexity of Problems
• In computational complexity theory, a decision problem is a computational problem that can be
  posed as a yes–no question of the input values.
  – Example 1: Prime Number
     Input: number 𝑛
     Question: Is 𝑛 a prime number?
     Output: YES (prime) or NO (not prime)
  – Example 2: Graph Connectivity
     Input: a graph G
     Question: Is there a path from node A to node B?
     Output:YES or NO
• Many optimization problems can be converted to decision problems.
