Representations of Integers
• In the modern world, we use decimal, or base 10, notation to represent integers. For
  example when we write 965, we mean 9∙102 + 6∙101 + 5∙100 .

• We can represent numbers using any base b, where b is a positive integer greater
  than 1.

• The bases b = 2 (binary), b = 8 (octal) , and b = 16 (hexadecimal) are important for
  computing and communications
