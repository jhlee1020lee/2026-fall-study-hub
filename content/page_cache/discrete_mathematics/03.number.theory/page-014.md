Heuristic Test
• Heuristic test example — Fermat Primality Test
Based on Fermat’s Little Theorem: If 𝑝 is prime and 𝑎 is not divisible by 𝑝, then 𝑎𝑝−1 ≡ 1 mod 𝑝


Example 1: 𝑛 = 17
                            16
Choose 𝑎 = 3 and compute 3 mod 17
Result: 316 ≡ 1 mod 17 , so the test suggests that 17 is prime.


Example 2: 561 = 3 × 11 × 17
But 2560 ≡ 1 mod 561 , so the test incorrectly suggests 561 might be prime.
