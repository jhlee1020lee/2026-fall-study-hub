Linear Map
                𝑛      𝑚
• A function 𝐹: ℝ → ℝ is called a linear map (aka linear transformation) if the
  following holds:
   1) ∀𝒖, 𝒗 ∈ ℝ𝑛 , 𝐹 𝒖 + 𝒗 = 𝐹 𝒖 + 𝐹 𝒗
   2) ∀𝒖 ∈ ℝ𝑛 and ∀𝑎 ∈ ℝ, 𝐹 𝑎𝒖 = 𝑎 ⋅ 𝐹 𝒖

• If 𝐹 is a linear map, then
     𝐹 𝑎1 𝒖1 + ⋯ + 𝑎𝑘 𝒖𝑘 = 𝑎1 𝐹 𝒖1 + ⋯ + 𝑎𝑘 𝐹(𝒖𝑘 )
