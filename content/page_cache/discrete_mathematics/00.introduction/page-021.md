 Is the Set of Real Numbers Countable
Assume, for contradiction, that all real numbers in 0 1 can be listed:
                                                      𝑟1 , 𝑟2 , 𝑟3 , 𝑟4 , …
Write each number in decimal form:
                                                 𝑟1 = 0. 𝑎11 𝑎12 𝑎13 …
                                                 𝑟2 = 0. 𝑎21 𝑎22 𝑎23 …
                                                 𝑟3 = 0. 𝑎31 𝑎32 𝑎33 …
                                                 𝑟4 = 0. 𝑎41 𝑎42 𝑎43 …
                                                 ⋮
Now construct a new number:
                                                   𝑥 = 0. 𝑏1 𝑏2 𝑏3 𝑏4 …
where each digit 𝑏𝑖 differs from the diagonal digit 𝑎𝑖𝑖 .
For example:
                                                            1 if 𝑎𝑖𝑖 ≠ 1
                                                   𝑏𝑖 = ቊ
                                                            2 if 𝑎𝑖𝑖 = 1
This guarantees:
• 𝑥 ≠ 𝑟1 ( differs in 1st digit)
• 𝑥 ≠ 𝑟2 ( differs in 2nd digit)
• 𝑥 ≠ 𝑟3 and so on... So 𝑥 is not in the list — contradiction!
