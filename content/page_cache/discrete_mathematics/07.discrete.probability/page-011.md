 Assigning Probabilities
• Laplace’s definition from the previous section, assumes that all outcomes are equally
  likely. Now we introduce a more general definition of probabilities that avoids this
  restriction.

• Let S be a sample space of an experiment with a finite number of outcomes. We assign
  a probability p(s) to each outcome s, so that:
  – 0 ≤ 𝑝 𝑠 ≤ 1 for each 𝑠 ∈ 𝑆
  – σ𝑠∈𝑆 𝑝 𝑠 = 1


• The function 𝑝 from the set of all outcomes of the sample space 𝑆 is called a probability
  distribution
