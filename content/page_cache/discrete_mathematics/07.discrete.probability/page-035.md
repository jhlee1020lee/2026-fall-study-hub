 Random Variables
• Definition: A random variable is a function from the sample space of an experiment to
  the set of real numbers. That is, a random variable assigns a real number to each
  possible outcome.
   – 𝑋: 𝑆 → ℝ
   – A random variable is a function. It is not a variable, and it is not random!

• Definition: The distribution of a random variable X on a sample space S is the set of pairs
  (r, p(X = r)) for all r ∊ X(S), where p(X = r) is the probability that X takes the value r.


• Example: A coin is flipped three times. Let X(t) be the random variable that equals the
  number of heads that appear when t is the outcome.
  – p(X = 3) = 1/8, p(X = 2) = 3/8, p(X = 1) = 3/8, and p(X = 0) = 1/8.
