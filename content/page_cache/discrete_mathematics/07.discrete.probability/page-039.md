 The Geometric Distribution
• Definition: A random variable X has geometric distribution with parameter p if p(X = k) =
  (1 − p)k-1p for k = 1,2,3,…, where p is a real number with 0 ≤ p ≤ 1.

• Theorem: If the random variable X has the geometric distribution with parameter p, then
  E(X) = 1/p.
  – The sample space is {T, HT, HHT, HHHT, HHHHT, …}.
  – Let X be the random variable equal to the number of flips in an element of the sample space;
   X(T) = 1, X(HT) = 2, X(HHT) = 3, etc.
