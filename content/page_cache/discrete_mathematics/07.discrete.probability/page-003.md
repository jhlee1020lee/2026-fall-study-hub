Probability of an Event
• We first study Pierre-Simon Laplace’s classical theory of probability, which he introduced
  in the 18th century, when he analyzed games of chance.
• We first define these key terms:
   – An experiment is a procedure that yields one of a given set of possible outcomes.
   – The sample space of the experiment is the set of possible outcomes.
   – An event is a subset of the sample space.

• Definition (Laplace): If S is a finite sample space of equally likely outcomes, and E is an
  event, that is, a subset of S, then the probability of E is p(E) = |E|/|S|.

• For every event E, we have 0 ≤ p(E) ≤ 1. This follows directly from the definition because
  0 ≤ p(E) = |E|/|S| ≤ |S|/|S| ≤ 1, since 0 ≤ |E| ≤ |S|.
