 Basic Counting Principles: Subtraction Rule
• The Sum Rule: If a task can be done either in one of n1 ways or in one of n2, where none
  of the set of n1 ways is the same as any of the n2 ways, then there are n1 + n2 ways to do
  the task.


• Subtraction Rule: If a task can be done either in one of n1 ways or in one of n2 ways,
  then the total number of ways to do the task is n1 + n2 minus the number of ways to do
  the task that are common to the two different ways
  – Also known as, the principle of inclusion-exclusion:
                              𝐴∪𝐵 = 𝐴 + 𝐵 − 𝐴∩𝐵
