Examples
• If |A| = m and |B| = n, then there are nm functions f : A → B.
   – For each element a ∈ A, there are n possible choices for f(a), because |B| = n. As
     there are m elements in A, there are nm functions from A to B.

• If |A| = m and |B| = n, how many one-to-one functions f : A → B are there?
  – There is no one-to-one function if m > n
  – If m ⩽ n, then there are n·(n−1)···(n−m+1) = n!/(n − m)! different functions
