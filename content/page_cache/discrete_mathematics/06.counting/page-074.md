 Permutation
• Definition: A permutation of a set of distinct objects is an ordered arrangement of these
  objects. An ordered arrangement of r elements of a set is called an r-permutation.

• Example: Let S = {1,2,3}.
   – The ordered arrangement 3,1,2 is a permutation of S.
   – The ordered arrangement 3,2 is a 2-permutation of S.

The number of r-permutations of a set with n elements is denoted by P(n,r).
  – The 2-permutations of S = {1,2,3} are 1,2; 1,3; 2,1; 2,3; 3,1; and 3,2. Hence, P(3,2) = 6.
