 Basic Counting Principles: The Sum Rule
• The Sum Rule: If a task can be done either in one of n1 ways or in one of n2, where none
  of the set of n1 ways is the same as any of the n2 ways, then there are n1 + n2 ways to do
  the task.

• The sum rule can be phrased in terms of sets:
              |A ∪ B|= |A| + |B| if A and B are disjoint sets.



• The case where the sets have elements in common will be discussed when we consider
  the subtraction rule later.
