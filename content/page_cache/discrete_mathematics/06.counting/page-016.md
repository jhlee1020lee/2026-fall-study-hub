Merge Sort
• Merge Sort works by iteratively splitting a list (with an even
  number of elements) into two sublists of equal length until each
  sublist has one element.
• Each sublist is represented by a binary tree.
• At each step a pair of sublists is successively merged into a list
  with the elements in increasing order. The process ends when
  all the sublists have been merged.
• The succession of merged lists is represented by a binary tree.
