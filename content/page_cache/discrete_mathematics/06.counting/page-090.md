 Permutations with Repetition
• Thm: The number of r-permutations of a set of n objects with repetition allowed is nr.
• Proof: There are n ways to select an element of the set for each of the r positions in the r-
  permutation when repetition is allowed. Hence, by the product rule there are nr r-
  permutations with repetition.
