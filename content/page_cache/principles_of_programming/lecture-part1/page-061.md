```text
Currying and Uncurrying
 • A function of type

        (T1,T2,…,Tn)=>T

  can be turned into that of type

       T1=>(T2=>(…=>(Tn=>T)…))

 • This is called “currying” named after Haskell Brooks Curry.
 • The opposite direction is called “uncurrying”.
```
