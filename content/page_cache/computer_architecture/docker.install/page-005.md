Environment Setup
1. Install Docker (Mac - option1)

I. Download Docker Desktop for Mac.
II. Select Apple chip (M1/M2/M3) or Intel chip depending on your
Mac.

III. Open the .dmg file and drag Docker.app into Applications.
IV. Launch Docker.app and check that the whale     icon appears in
the menu bar.
