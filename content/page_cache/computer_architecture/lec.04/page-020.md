                Standard Benchmarks

Why standard benchmarks?
  ➟ Everyone cares about different applications (different aspects of
   performance)
  ➟ Provide a “standard” performance aspect over a machine

SPEC Benchmarks (www.spec.org)
  ➟ Standard Performance Evaluation Corporation
  ➟ A set of “realistic”, general-purpose, public-domain applications chosen by
   a multi-industry committee
  ➟ Updated every few year to reflect changes in usage and technology
  ➟ Everyone knows it is not perfect, but at least everyone plays/cheats by
    the same rules
