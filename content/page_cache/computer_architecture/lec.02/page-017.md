                              Evolution of ISA

Early ISAs were simple (e.g. EDSAC)
   ➟ Technology limitation
   ➟ Inexperience, lack of precedence

ISAs got complicated later (e.g. VAX11) - Complex Instruction Set Computer (CISC)
   ➟ Assembly programming
   ➟ Microprogrammed implementation

ISAs are now simple again (e.g. RISC-V) - Reduced Instruction Set Computer (RISC)
   ➟ Memory size and speed (cache!)
   ➟ Compilers (easy to optimize)

Why x86 is still “king of the hill”?
   ➟ Technology == economics
   ➟ Technology == psychology
   ➟ Technology == deep pocket
