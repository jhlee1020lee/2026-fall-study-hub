Recap: How to specify what a computer does?

   Architecture (ISA) Level (e.g., x86-64 used by Intel and AMD CPUs)
       ➟ Car: driving manual & operation manual
       ➟ Computer: instruction manual (the set of instructions that the CPU can run)


   Microarchitecture (implementation) Level (e.g., Intel Alder Lake, AMD Zen 4)
       ➟ A particular car design has a certain configuration (e.g., v8 engine vs. v4 engine)
       ➟ A particular computer design has a certain configuration (e.g., 4M cache vs. 1M
        cache)


   Circuit (= physical implementation) level (not covered in this course)
       ➟ Car: metal sheets, cranks, shafts, gears, …
       ➟ Computer: gates, wires, semiconductor, transistors, …
