                  Wrap-up: Terminologies
Instruction Set Architecture (ISA)
  ➟ The machine behavior as observable and controllable by the programmer


Instruction Set
  ➟ The set of commands understood by the computer


Machine Code
  ➟ A collection of instructions encoded in binary format
  ➟ Directly interpretable by the hardware


Assembly Code
  ➟ A human-readable notation for ISA instructions e.g. Add r1, r2, r3
  ➟ Translated into machine code by an assembler
  ➟ Pseudo-instructions may expand to multiple machine instructions
