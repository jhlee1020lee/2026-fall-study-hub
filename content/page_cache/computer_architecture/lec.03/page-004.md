               Recap: Instruction Set
The repertoire of instructions of a computer


Different computers have different instruction sets
  ➟ Intel processors use the x86-64 instruction set
  ➟ ARM processors use the ARM instruction set
  ➟ But with many aspects in common (arithmetic operations, control
   flow, …)


Early computers had very simple instruction sets
  ➟ Simplified implementation
  ➟ Later, it gets more complex and then become simple again
