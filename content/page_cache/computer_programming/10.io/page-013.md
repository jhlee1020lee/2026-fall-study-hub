Java File Path
• You can specify either relative path or full path.
• Relative path (e.g., “say_hello.txt”)
   • By default, the file is searched in the working directory.
      • IntelliJ sets the project root as the default working directory.
• Full path (e.g., “c:/java_program/say_hello.txt”)
   • The file is searched from the specified directory.
