This Course: Computer Programming
• We learn Java and C++, but mostly as a tool to study OOP.
   • Java lets us concentrate on OOP without managing memory directly.
   • C++ lets us revisit OOP while making resource management explicit.
   • The underlying design principles remain similar.
• Our goal is to develop ideas that transfer to other languages!
   • OOP as a generalizable principle, not as a syntax.
