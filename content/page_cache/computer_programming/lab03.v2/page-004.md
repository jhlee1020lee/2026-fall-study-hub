Recap: Object-Oriented Programming
● Looking at software systems as a collection of interactive objects
● Features of OOP
  ● Encapsulation
      ● Inner implementations are invisible
      ● Protects data of an object from the outside
      ● Makes it easier to abstract
  ● Inheritance
      ● Classes can inherit properties of other classes
           ● i.e. A child class inherits the properties/characteristics of its parent class
      ● Makes it easier to reuse codes
  ● Polymorphism
      ● Methods with the same name can be implemented differently in classes that have the
          same parent class
      ● Makes it easier to diversify behaviors
