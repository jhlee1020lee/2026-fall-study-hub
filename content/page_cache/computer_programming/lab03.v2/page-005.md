Objects and Classes
● Objects represent entities
● Classes are the blueprints of the objects
  ● Classes use attributes (variables) and methods (functions) to depict objects
  ● An object is created from a class
       ● We can create multiple objects from a single class
       ● Objects created from the same class will have similar characteristics
           ● They will have common attributes and methods
