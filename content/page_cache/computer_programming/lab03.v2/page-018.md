Problem 1 : Fighting Game Simulation
● Students will be required to create a program in which two players fight
    each other. During each round, the players will take turns attacking
    and/or healing. After the final round, the program should determine the
    winner of the fight/game.
●   There are three classes you will be required to implement :
    ● The Player Class
    ● The Fight Class
    ● The Main Class
