Problem 1-2 : Create the Fight Class
● The Fight Class manages the interactions between the players.
● This class keeps track of the rounds of the fight.
  ● During each round, a fight instance runs players’ actions starting with Player p1.
● A fight ends when one of the players loses all of his/her health points or
    when the final round ends.
    ● The fight starts at round 1 and ends at round 100.
