Methods (= Member Functions)
• Define a way that an object perform actions.
• Objects can call a method with dot(.) operator followed by a
  method name and parentheses ().

  class Car {
     void printHello() {
         System.out.println("Hello World!");
     }
  }
  Car car = new Car();
  car.printHello();
