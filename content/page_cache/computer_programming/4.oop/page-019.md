Constructors
• Special class methods to initialize an object.
   • A constructor is called once when the instance is created.
• The name of the constructor is the same as that of the class.
• There is no return type of a constructor.
• You cannot explicitly call a constructor.
   • To be precise, you can call a constructor in other constructors.
   • This will be explained later.
