Attributes Initialization
• Attributes can be initialized with constant values when declared.
• If not initialized explicitly, they have default values.
   • false (boolean)
   • 0 (int)
   • 0.0 (float)
   • ‘’ (char)
   • ...
   • null (Object attributes)
