this keyword
• It is a special keyword used to indicate the “self-object”.
• You can usually omit this keyword, but sometimes you need it.
• Used to explicitly indicate attributes (vs. local variables).
   • If there is a parameter or a variable with the same name.
• Used to explicitly call a constructor of the object: this().
   • This will be explained later when we study polymorphism.
