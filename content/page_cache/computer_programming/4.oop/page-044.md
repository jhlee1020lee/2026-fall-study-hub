Memory Management in Java
• Memory management in Java is dynamic and automatic.
  • When you create a new object, it allocates the right amount of memory.
  • ⇔ C program: You have to allocate memory for objects explicitly.
• Java has a garbage collector.
  • It looks for unused objects and reclaims the memory that they are using.
  • ⇔ C program: You have to free memory explicitly.
