Method Call: Call-by-Reference
• Call-by-reference refers to a way to call a function, passing a
  variable reference pointing to the variable's memory space.
• In Java, passing an object is done by call-by-reference.
• Thus, you can change the object's attributes inside the method.
• This as “call-by-value” if we think of the memory address values.
