Problem 1-2 : Validation Logic
● Check whether the input string is a valid student ID or not in the
   following order, and print the corresponding messages.
    1. The length of the input should be 10.
       -> If not, print “The input length should be 10."
    2. The 5th character of the input should be ‘-’.
       -> If not, print “Fifth character should be `-`."
    3. All characters of the input but the 5th input should be digits.
       -> If not, print “Contains an invalid digit."
    4. If 1~3 are all satisfied, print “XXXX-XXXXX is valid.”
