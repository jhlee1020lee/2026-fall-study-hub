Problem 1-2 : Validation Logic
Here are some tips…
● You can use the .charAt method of the String class
    to get a character at a specific index.
● A character can be converted to its Unicode index (https://unicode-
    table.com/en/). This is useful when checking if a character belongs to
    specific category.
     ○ Digit: ch >= '0' && ch <= '9'
     ○ Non-Digit: ch < '0' || ch > '9'
     ○ Lowercase Alphabet: ch >= 'a' && ch <= 'z'
     ○ Uppercase Alphabet: ch >= 'A' && ch <= 'Z'
