Problem 2-3 : NxN TicTacToe

● Extend the game to use an NxN board, where N is also an
  integer input from the console.
● Assume the first input is N, and the rest of the NxN inputs
  represent the board.
● Assume N >= 3.
● All the rules are same, but now the players have to place N
  consecutive marks in a horizontal / vertical / diagonal row.

                          0   1   0    1

                          1   1   0    1

                          0   0   1    1

                          0   0   0    1                         32
