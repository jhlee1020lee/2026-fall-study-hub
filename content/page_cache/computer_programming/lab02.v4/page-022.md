Problem 2 : TicTacToe

● In the TicTacToe.java file, write a program that determines the
  winner of the Tic-Tac-Toe game given a board.
● Tic-Tac-Toe is a two player game that uses a 3x3 board. Each
  player alternately places his/her mark on an empty cell of the
  board.
● The first player who succeeds in placing his/her marks in a
  horizontal, vertical, or diagonal row is the winner.
