Problem 2-2 : Determine Winner

● Determine the winner of the game (who placed his/her
  marks in a horizontal, vertical, or diagonal row.)
● If Player 0 won, print Player 0 win.
● If Player 1 won, print Player 1 win.
● If none of them succeeded in winning, print Tie.
● If (1) both of them succeeded in winning, or
  (2) the number of marks of the two players differ by more
  than 1, print Invalid game.
