● Encapsulation
  ● One of the fundamental concepts in Object-Oriented Programming
      ● Bundling non-visible attributes with visible methods
  ● Characteristics
      ● Abstraction
          ● Define public abstractions to interact with an object
      ● Defensive Programming
          ● Protect data from unauthorized access
          ● Hide internal details of change in data
