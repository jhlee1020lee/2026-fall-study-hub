Types of Inheritance
• Single inheritance:
  • Inheriting features of only one superclass.
• Multi-level inheritance:
  • Derived class also acts as the base class to
    others.
• Hierarchical inheritance.
  • A class serves as a superclass for more than
    one subclass.
