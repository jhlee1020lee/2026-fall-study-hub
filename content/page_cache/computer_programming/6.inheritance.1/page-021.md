The Object Class
• All classes inherit the methods of the Object class.
   • toString() returns a String representation of the object.
   • getClass() returns the Class object that represents the class.
   • equals() defines a notion of value-based object equality.
   • finalize(), clone(), hashCode(), wait(), notify(), notifyAll()
• Classes can redefine these methods by overriding them.
