Use Case 2: Comparable<T> Interface
• It contains an abstract method int compareTo(T obj).
• obj1.compareTo(T obj2) returns
  • positive int if obj1 is ‘greater’ than obj2
  • negative int if obj2 is ‘greater’ than obj1
  • 0 if obj1 and obj2 are the same
