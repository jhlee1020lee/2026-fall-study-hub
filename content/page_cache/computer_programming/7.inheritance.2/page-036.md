Use Case 2: Comparable<T> Interface
• Interface Comparable<T> is implemented to make user-defined
  objects comparable (and sortable).
• It can be used to compare objects based on selected attributes.
  • Naive comparison between numbers
  • ASCII code comparison between characters
• Comparable Objects are sortable with Collections.sort().
