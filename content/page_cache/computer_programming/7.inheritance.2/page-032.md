Why Use Interface in Java?
• Use case 1: Provide a blueprint for the implementing classes.
  • An interface forces them to implement all the abstract methods.
• Use case 2: Provide a known interface for broader use cases.
  • By enforcing input and output types, the implementing classes behave
    predictably, regardless of the actual implementation.
