Binding in Java
• Binding explains how overriding and hiding affect method calls.
• Static Binding
   • Variables are bound statically to a type at the compilation time.
   • E.g., private, final and static methods
• Dynamic Binding
   • Types of variables are unknown during the compilation.
   • They are bound dynamically at the runtime by JVM.
   • E.g., overridden methods
