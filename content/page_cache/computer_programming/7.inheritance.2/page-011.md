Dynamic Binding: Object Class
• Two widely-used overridden methods are:
  • toString() (declared in the Object class)
  • equals() (declared in the Object class)
     • hashcode() is often overridden together with equals().
• JVM dynamically determines which methods to call.
  • Depending on the actual type of the object.
