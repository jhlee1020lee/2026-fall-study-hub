Use Case 1: List<E> Interface
• java.util.List is an interface that acts as a blueprint for
  different types of lists (ordered collections).
   • ArrayList<E>, LinkedList<E>, Stack<E>, Vector<E>, etc.
   • <E> indicates the type of elements to store.
   • For instance, ArrayList<Integer> stores int elements.
• All the lists support common list operations.
   • add(), get(), remove(), set(), etc.
• More details will be covered later.
