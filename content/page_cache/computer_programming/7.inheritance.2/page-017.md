equals() Example
• equals() returns the equality of two objects.
   • Object.equals() checks their memory addresses (==).
   • We can override it to check their attributes.
• All the classes can override the equals() method.
   • Object class has the equals() method.
   • Signature: public boolean equals(Object obj){ ... }
• Note: == and equals() are the same for primitive types.
