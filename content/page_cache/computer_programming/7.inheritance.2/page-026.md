Interface
• An interface is a blueprint of a class, but NOT a class.
   • It forces a class to contain certain methods and attributes.
• All the methods in an interface do not have an implementation.
   • We call them abstract methods.
• A class can implement multiple interfaces.
   • While it cannot inherit multiple classes.
