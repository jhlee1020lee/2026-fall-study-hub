Interface Syntax: Attributes
• Interfaces can have attributes.
• Attributes are by default public, static, and final.
   • Even though you do not use these keywords.
   • Note: their values cannot be changed in implementations.
• It triggers a compilation error if
   • We use a conflicting modifier.
   • We leave a field uninitialized.
