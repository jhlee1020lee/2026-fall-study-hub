Abstract Class vs. Interface
• Use an interface when:
  • You want different kinds of objects to support the same operations.
  • A class needs multiple interfaces while extending another class.
• Use an abstract class when:
  • Related classes share instance fields and method implementations.
  • You need constructors for common initialization.
  • You need protected helper methods.
