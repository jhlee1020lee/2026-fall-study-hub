equals() vs. compareTo()
• equals() is a method implemented in the Object class.
• compareTo() is an abstract method in the Comparable interface.
• Equality is a property that can be shared by all objects in Java.
• Comparability is not necessarily common across all objects.
• Comparable interface imposes total ordering on the comparable
  objects; some entities cannot be totally ordered.
