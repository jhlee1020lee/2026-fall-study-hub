Operator Overloading: +
• For numbers, + performs addition.
• If either operand is a String, + concatenates strings.


   int sum = 10 + 20;                    // 30
   double total = 1.5 + 2.0;             // 3.5

   String text = "10" + "20";            // "1020"
   String label = "sum = " + 30;         // "sum = 30"
