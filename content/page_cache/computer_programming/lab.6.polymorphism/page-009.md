       Recap: Generics - Wildcards
       The ? (question mark) symbol is a wildcard element.
             • static void printCollection(Collection<?> c)

       It is used to restrict a type together with the “extends” or
       “super” keywords.
             • private static Double reduce(ArrayList<? extends
                  Number> num)
             • public static void addNumbers(List<? super Integer>
                  list)
