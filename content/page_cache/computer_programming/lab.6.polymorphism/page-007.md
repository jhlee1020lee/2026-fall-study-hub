Recap: Generics
A method, class or interface defined with a type variable, and
thus applicable to arbitrary types.
-> Considered as parametric polymorphism

Usage
  ○ Generic Class: a class declaring one or more type variables.
      • class Wrapper<T> { ... }
  ○ Generic Methods: a method declaring one or more type variables.
      • public static <E> void printArray(E[] elements)
