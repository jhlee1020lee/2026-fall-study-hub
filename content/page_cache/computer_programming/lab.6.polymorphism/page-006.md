Recap: Overriding
To redefine an inherited instance method of a subclass to change
or extend the behavior of the parent’s corresponding method.
    ○ Ex. Manager inherits Employee. (getSalary())




We can override methods of the class Object to suit the purpose
of our own classes.
   ○ @Override public string toString()
   ○ @Override public boolean equals (Object o)
