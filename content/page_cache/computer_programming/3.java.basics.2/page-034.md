For Loop Example
• Statement 1 initializes a variable before the loop starts (i = 0).
• Statement 2 defines the condition for the loop to run (i < 5).
• Statement 3 (i++) increases i each time the code is executed.


  for (int i = 0; i < 5; i++) {
     System.out.println(i);
  }
