For-Each Loop
• A particular type of for loops to easily iterate through an array.
• You declare a loop variable that is the same type as the base type
  of the array, followed by a colon and the array name.
• You can use the variable in the body to iterate through the array.


 for (type variable : arrayname) {
     // code block to be executed
 }
