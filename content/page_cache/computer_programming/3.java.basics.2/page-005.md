Array Initialization
• To declare and initialize an array, we can use an array literal.
   • Place the values in a comma-separated list, inside curly braces { }.


// Size of an array in [] should be omitted
// Otherwise, an error will occur
type[] variableName = new type[] {obj1, obj2, ...};

// new, type, and [] can be omitted
type[] variableName = {obj1, obj2, ...};
