If Statement
• Use if statement to conditionally execute a block of Java code.
   • The condition can be specified as a boolean expression, a combination of
     boolean variables, logical operators, and comparison operators.



 // “if” should be lowercase (If X, IF X)
 if (condition) {
    // block of code to be executed if the condition is true
 }
