Switch Statement without Break
• Note: switch statement does not work intuitively.

 char grade = 'B';
 switch (grade) {
    case 'A':
        System.out.println("Your score is 4.");
    case 'B':
        System.out.println("Your score is 3.");
    default:
        System.out.println("There is no grade " + grade + ".");
 }
