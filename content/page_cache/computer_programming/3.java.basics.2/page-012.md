Accessing a Value in a 2D-Array
• Specify two indexes to access an element.
• The first index indicates the “row” (i.e., which array).
• The second index indicates the “column” (i.e., which element).
• The below example accesses the 2nd array’s 3rd element.


  int[][] myNumbers = {{1, 2}, {3, 4, 5}};
  System.out.println(myNumbers[1][2]); // 5
