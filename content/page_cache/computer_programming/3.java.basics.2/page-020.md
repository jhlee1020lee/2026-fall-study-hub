Else If Statement
• Use else if statement to evaluate a secondary condition.
• It is the same as if statement inside an else statement.

 if (condition1) {
    // executed if condition1 is true
 } else if (condition2) {
    // executed if the condition1 is false and condition2 is true
 } else {
    // executed if the condition1 is false and condition2 is false
 }
