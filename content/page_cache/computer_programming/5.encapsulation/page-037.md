Access Modifiers for Classes
• public class
  • Accessible by all classes (in different packages).
  • Only 1 public class can exist for each .java file (same name).
• (default) class
  • Accessible by classes in the same package.
  • Helper classes that work only for a public class.
     • Need not be visible from the outside of the package.
