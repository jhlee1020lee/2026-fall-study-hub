Access Modifiers
• Access modifiers declare a proper access level.
• You can use one of the following:
  • private: The code is only accessible within the declared class.
  • default: The code is accessible only in the same package.
     • This is used when you don’t specify a modifier.
  • protected: Accessible in the same package and inherited child classes.
  • public: The code is accessible by all classes.
