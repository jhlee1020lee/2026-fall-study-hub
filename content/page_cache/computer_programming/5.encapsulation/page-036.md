Using a Class in a Different Package
• There are different ways to access a class in a different package.
• Import all the classes in a package using *.
   • import computer.*;
• Import a specific class in a package.
   • import computer.Keyboard;
• Use a full name using “package.classname”.
   • computer.Keyboard k = new computer.Keyboard();
