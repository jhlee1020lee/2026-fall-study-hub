Java Packages
• A group of similar types of classes, interfaces, and sub-packages.
   • This can be considered as a different level of encapsulation.
   • Java packages provide access protection.
   • Java packages remove naming collision.
• There are built-in packages and user-defined packages.
   • Built-in packages include java, lang, awt, javax, io, util, etc.
