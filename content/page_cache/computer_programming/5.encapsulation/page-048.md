Summary: Benefits of Encapsulation
• Flexibility: Flexible and easy to change the encapsulated code.
• Reusability: Encapsulated code can be easily and safely reused.
  • Throughout the application or across multiple applications.
• Maintainability: Application code is encapsulated in separate
  units (classes, interfaces, methods, setters, getters, etc.).
  • Easy to update a part of the application without affecting other parts.
