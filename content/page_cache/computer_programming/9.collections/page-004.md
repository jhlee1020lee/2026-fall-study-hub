Motivation
• Arrays are useful to manage objects but have limitations:
   • Its size is fixed upon initialization.
   • It occupies a fixed-size memory space, irrelevant of the # of objects.
   • It is hard to change the positions of already placed objects.
• We need better data structures to manage a group of objects.
