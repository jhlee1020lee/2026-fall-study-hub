ArrayList Operation Details
• Size is the number of elements in the list.
• Capacity is the length of its internal array.
• When the array is full, adding an element creates a larger array.
   • Typically by about 50%.
   • The exact policy depends on the implementation.
• Removing an element decreases size but not capacity.
   • Any subsequent elements shift left.
