Java Collections Framework
• Java collections framework is an easy and unified way for
  representing and manipulating collections.
   • A collection groups multiple objects into a single unit.
   • For instance, ArrayList, HashSet, and TreeMap are collections.
• It consists of interfaces and implementations.
   • It is important to choose a suitable interface and implementation.
