LinkedList Class
• LinkedList is implemented based on a chain of nodes.
   • Storing an element and two references to the next and previous nodes.
• It does not pre-occupy consecutive memory space.
   • Thus, adding or deleting an element can be efficient.
• It takes significant time to get an element with an index.
   • It navigates nodes from the beginning one by one.
• It is defined in java.util.LinkedList.
