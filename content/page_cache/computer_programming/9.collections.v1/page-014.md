List Interface
• An “ordered” collection (a.k.a. a sequence).
   • Precise control over where in the list each element is stored.
   • Access elements in the list by their integer index (i.e., position).
• Lists allow duplicate elements.
   • Allow e1 and e2 to be in a list such that e1.equals(e2).
• It is defined in java.util.List.
