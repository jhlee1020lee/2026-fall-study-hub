ArrayList Class
• ArrayList is implemented based on an array, but its size grows
  dynamically as elements are added.
• It is fast to access any element in ArrayList, given an index.
• However, it is slow to add or delete an element in ArrayList.
   • Why? You need to shift multiple elements.
• It is defined in java.util.ArrayList.
