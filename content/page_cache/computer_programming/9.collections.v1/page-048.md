HashSet Using Hasing
• Hashing uses an array of linked lists.
   • hashcode() is used to index into the array.
   • equals() is used to determine if the element is in the (short) list.
• hashcode() and equals() must be compatible.
   • If two objects are equal, they must have the same hashcode() value.
