ArrayList Methods
• The get and set methods of the List interface are provided.
   • Object get(int index)
   • Object set(int index, Object element)
• Indexed add and remove are provided, but they are inefficient.
   • void add(int index, Object element)
   • Object remove(int index)
• You can easily resize the list if you need to add more items.
   • void ensureCapacity(int minCapacity)
