# Java compile and run(자바 컴파일과 실행)

## 정의

Compile(컴파일)은 저장한 Java source file(소스 파일)을 다음 실행 단계에서 사용할 class file(클래스 파일)로 만드는 작업이고, run(실행)은 그 class의 프로그램을 동작시키는 작업이다. 이번 실습에서 `javac HelloWorld.java`는 `HelloWorld.class`를 생성하며, 이어서 `java HelloWorld`를 실행하면 `Hello World!`가 출력된다. 두 명령은 역할과 인자 형식이 다르다.
