# von Neumann architecture

## 정의

1. 과목의 목표, 평가, RISC-V·Chisel 실습 구성을 안내했다. Lab 1~2는 single-cycle CPU, Lab 3은 five-stage pipelined CPU, Lab 4는 branch prediction을 다룬다. [STT 01:58-08:38] [M01 p.3-6]
2. 컴퓨터구조를 software와 digital circuit 사이의 abstraction으로 정의했다. [STT 13:36-17:56] [M01 p.9-11]
3. ISA와 microarchitecture를 구분하고, 같은 ISA에 여러 구현이 존재할 수 있음을 설명했다. [STT 15:25-17:56] [M01 p.11]
4. **von Neumann architecture**와 Harvard architecture, CPU·memory·I/O의 전형적 구성을 살펴봤다. [STT 21:31-26:01] [M01 p.14-15]
5. transistor를 스위치로 보고 NAND 같은 logic gate를 구성하는 방향을 짚었다. [STT 28:29-31:30] [M01 p.19-20]
6. Moore's Law, Dennard scaling의 붕괴, multicore 전환을 통해 현대 CPU 설계의 배경을 설명했다. [STT 32:11-40:38] [M01 p.22-27]
7. 학기 후반에는 GPU 설계 개요와 hardware security
