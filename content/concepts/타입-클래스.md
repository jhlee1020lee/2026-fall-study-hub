# Type Class(타입 클래스)

## 정의

Type class(타입 클래스)는 이 강의에서 큰 프로그램의 abstraction(추상화)과 code reuse(코드 재사용)를 조직하는 방식으로 소개된다. 자료는 type(타입)과 method(메서드)로 이루어진 type class instance(타입 클래스 인스턴스)를 구성 단위로 제시하고, type class instantiation(타입 클래스 인스턴스화)을 통한 abstraction과 composition(합성)을 통한 code reuse를 구분한다. 구체적인 문법과 설계는 이후 과목 부분의 학습 대상이다.
