# IntelliJ IDEA

## 정의

IntelliJ IDEA는 이번 수업에서 Java 프로그램을 작성하고 실행하는 데 사용하는 IDE(통합 개발 환경)다. 이 실습에서는 project(프로젝트)에 `HelloWorld` class(클래스)를 만들고, run configuration(실행 구성)에서 실행할 main class(메인 클래스)를 선택한다. Run을 실행하면 IntelliJ가 필요한 Java code(코드)를 자동으로 compile(컴파일)한 뒤 main method(main 메서드)를 실행한다.
