# Function Application(함수 적용)

## 정의

Function application(함수 적용)은 function(함수)에 argument(인자)를 주어 계산을 수행하는 것이다. 이번 evaluation(평가) 규칙에서는 argument를 먼저 value(값)로 만든 뒤, function 본문의 해당 parameter(매개변수)를 그 value로 치환한다. `f(10)` 전체가 치환된 본문 expression(식)으로 바뀌며, function name(함수 이름)만 임의로 교체하는 것은 아니다.
