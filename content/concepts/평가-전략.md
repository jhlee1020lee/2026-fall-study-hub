# Evaluation Strategy(평가 전략)

## 정의

Evaluation strategy(평가 전략)는 function application(함수 적용) 등에서 어떤 expression(식)을 언제 평가할지 정하는 방식이다. 이번 회차에서는 argument(인자)를 먼저 value(값)로 평가한 뒤 function(함수) 본문에 전달하는 규칙을 사용했다. 자료의 Call-by-value(값에 의한 호출)와 Call-by-name(이름에 의한 호출)의 상세 비교는 다음 수업으로 명시적으로 미뤄졌으므로 이번 회차에서 모두 배웠다고 보지 않는다.
