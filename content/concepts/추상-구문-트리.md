# Abstract Syntax Tree(AST; 추상 구문 트리)

## 정의

Abstract syntax tree(추상 구문 트리, AST)는 expression(식)이 어떤 부분식들로 구성되는지 나타내는 나무 구조이다. `5 + b`의 구조를 펼친 도식에서는 전체 덧셈 아래에 각 부분식이 놓인다. AST의 바깥 구조를 먼저 확인하는 것과 안쪽 operand(피연산자)의 계산을 먼저 완료하는 것은 서로 다른 단계이다.
