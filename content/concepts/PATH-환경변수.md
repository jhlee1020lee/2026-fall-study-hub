# PATH environment variable(PATH 환경 변수)

## 정의

PATH environment variable은 이번 Windows 실습에서 PowerShell이 Java 명령의 위치를 찾도록 점검하는 설정이다. 자료는 Java 명령이 인식되지 않을 때 설치한 JDK(자바 개발 도구 모음)의 `bin` 위치를 Path에 추가하고, 변경을 저장한 뒤 PowerShell을 닫았다가 다시 열어 `java -version`으로 확인하도록 안내한다. 이는 명령을 찾지 못하는 상황의 점검 절차이며, 모든 Java 오류의 원인이나 해결책을 뜻하지 않는다.
