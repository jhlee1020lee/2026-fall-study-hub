# Java Runtime Environment(JRE; 자바 실행 환경)

## 정의

JRE는 Java 프로그램을 실행하는 데 필요한 환경이다. 강의의 구성도에서는 JVM(자바 가상 머신)과 Java package classes(자바 패키지 클래스)를 함께 묶어 JRE로 표시하며, package classes의 예로 `util`, `math`, `lang`을 든다. JRE의 실행 지원 역할과 development tools(개발 도구)를 더한 JDK(자바 개발 도구 모음)의 역할을 구별한다.
