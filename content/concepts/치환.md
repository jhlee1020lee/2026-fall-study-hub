# Substitution(치환)

## 정의

Substitution(치환)은 이 강의의 function application(함수 적용) 규칙에서 function(함수) 본문의 parameter(매개변수)를 실제 argument value(인자 값)로 바꾸는 것이다. `def f(x: Int): Int = x + a`에 `f(10)`을 적용하면 본문은 `10 + a`가 된다. `a`는 해당 parameter가 아니므로 자신의 별도 정의를 유지한다.
