# Code Reuse(코드 재사용)

## 정의

Code reuse(코드 재사용)는 이미 작성한 공통 계산을 여러 상황에서 다시 활용하는 것이다. `sum(10)`과 `sum(100)`은 서로 다른 입력으로 같은 function(함수) 정의를 사용한다. 세부 구현을 역할별 단위로 이해하는 abstraction(추상화)과는 목표를 구별해서 생각해야 한다.
