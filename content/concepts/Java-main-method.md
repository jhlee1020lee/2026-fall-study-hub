# Java main method(main 메서드)

## 정의

Main method는 이번 Java 예제에서 프로그램의 실행을 시작하는 method(메서드)다. `HelloWorld` class(클래스) 안에 `public static void main(String[] args)`로 작성되며, 그 안의 `System.out.println("Hello World!");`가 실행 결과를 출력한다. IntelliJ는 선택한 main class(메인 클래스)에 필요한 code(코드)를 compile(컴파일)한 뒤 이 main method를 실행한다. 각 구문의 상세한 의미는 이번 설치 실습에서 전개하지 않았다.
