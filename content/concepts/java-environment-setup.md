# Java environment setup(자바 환경 설정)

## 정의

Java environment setup은 이번 Lab 1에서 장치에 맞는 JDK(자바 개발 도구 모음)를 설치하고, 터미널에서 Java 명령을 인식할 수 있는지 확인하는 준비 과정이다. Windows에서는 PowerShell, macOS에서는 Terminal을 사용하며, 수업 자료가 제시한 채점 환경은 JDK 11.0.32.1이다. 설치 완료 화면, `java -version`의 출력, 이후 source(소스 코드)의 compile(컴파일)과 실행은 각각 별도로 확인할 단계다.
