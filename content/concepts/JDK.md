# Java Development Kit(JDK; 자바 개발 도구 모음)

## 정의

JDK는 Java 프로그램을 개발하는 데 필요한 도구를 포함하는 환경이다. 강의의 구성도에서는 JRE(자바 실행 환경)에 `javac`와 `java` 같은 development tools(개발 도구)를 더해 JDK를 설명한다. 이번 실습은 프로그램을 실행하는 데서 그치지 않고 source(소스 코드)를 작성하고 compile(컴파일)하므로 JDK를 설치한다. 이 도식은 기능 관계를 설명하며 모든 배포판의 실제 폴더 배치를 규정하지 않는다.
