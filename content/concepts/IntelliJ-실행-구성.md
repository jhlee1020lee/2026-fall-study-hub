# Run configuration(실행 구성)

## 정의

Run configuration은 IntelliJ에서 어떤 Java application(응용 프로그램)을 실행할지 지정하는 설정이다. 이번 실습에서는 Application 유형의 구성을 만들고 main class(메인 클래스)로 `HelloWorld`를 선택한다. Configuration의 표시 이름은 사용자가 정할 수 있지만, main class 선택은 실제 실행 대상을 정하므로 두 이름의 역할을 구별해야 한다.
