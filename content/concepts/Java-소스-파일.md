# Java source file(자바 소스 파일)

## 정의

Java source file은 Java code(코드)를 작성해 저장한 파일이며, 이번 실습에서는 `HelloWorld.java`를 사용한다. 파일 이름에 `.java`가 보이는 것과 실제 file extension(파일 확장자)이 `.java`인 것은 구별해야 하므로, 자료는 `.txt`가 남지 않았는지 확인하고 code를 입력한 뒤 저장하도록 안내한다. Source file은 compile(컴파일)의 입력이며, 그 결과로 생성되는 `HelloWorld.class`와는 다른 파일이다.
