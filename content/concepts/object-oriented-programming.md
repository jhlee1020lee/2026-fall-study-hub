# OOP

## 정의

Object-oriented programming(객체 지향 프로그래밍, OOP)은 상호작용하며 상태가 변하는 object(객체)를 중심으로 프로그램을 구성하는 방식이다. Procedural programming(절차적 프로그래밍)이 단계·function(함수)·operation(연산)의 순서로 프로그램을 구성한다면, OOP는 object들이 어떤 정보를 갖고 서로 어떻게 영향을 주는지에 주목한다. Java와 C++는 이 원리를 배우기 위한 도구이며, 강의의 목표는 다른 언어에도 적용할 수 있는 설계 관점을 익히는 것이다. [STT 18:55-22:29] [M01 p.11-12]

Java에서 class(클래스)는 object의 틀이고 method(메서드)는 class 안에서 정의하는 동작이다. [[concepts/primitive-and-reference-types|primitive type(기본 자료형)과 reference type(참조 자료형)]]의 차이를 익히면 object를 가리키는 variable(변수)을 추적할 수 있다. [[concepts/string-pool|String pool(문자열 풀)]]은 여러 variable이 같은 String object를 가리키는 예시와 연결된다. [STT 46:30-49:46, 01:11:45-01:15:24] [M02 p.15-17, p.47-49]
