# runtime monitor(실시간 모니터)

## 정의

정적 증명만으로 모든 현실 상황을 미리 모델링하기 어려울 수 있다. **runtime monitor**는 센서 입력과 명령을 관찰하고, 정해진 안전 규칙을 어기는 행동을 차단한다. 강의의 로봇 예시는 지능이나 행동의 자유를 조금 제한하더라도 사람이 이해할 수 있는 규칙을 통해 안전 보장을 얻는 절충을 보여 준다. [STT 39:43-42:50]
