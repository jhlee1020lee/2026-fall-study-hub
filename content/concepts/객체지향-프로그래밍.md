# Object-Oriented Programming(객체지향 프로그래밍)

## 정의

Object-Oriented Programming(객체지향 프로그래밍)은 data(데이터)와 method(메서드)를 묶은 object(객체)를 중심으로 큰 프로그램을 구성하는 방식이다. 이번 자료는 abstraction(추상화)과 code reuse(코드 재사용)를 공통 목표로 삼고, inheritance(상속)를 중심으로 구성하는 방식을 type class와 비교한다. 이 비교를 모든 언어·설계에서의 우열로 일반화하지 않는다.
