# Name Binding(이름 바인딩)

## 정의

Name binding(이름 바인딩)은 name(이름)이 어떤 expression(식)을 가리키는지 정하는 것이다. `def a = 1 + (2 + 3)`에서 `a`는 해당 expression을 가리키며, `a`를 평가할 때 정의된 expression을 펼친다. 이번 `def` 예시를 변경 가능한 저장 공간에 값을 덮어쓰는 동작과 동일하게 해석하지 않는다.
