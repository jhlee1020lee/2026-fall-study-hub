# Integrated Development Environment(IDE; 통합 개발 환경)

## 정의

IDE는 software development(소프트웨어 개발)에 필요한 기능을 한곳에 모은 application(응용 프로그램)이다. 이번 자료는 code editor(코드 편집기)의 autocomplete(자동 완성)·syntax highlighting(구문 강조), 자동 compile(컴파일)을 지원하는 build automation(빌드 자동화), debugger(디버거)를 주요 기능으로 든다. IDE는 단순히 파일을 편집하는 화면이 아니라 반복되는 개발 작업을 통합하는 도구다.
