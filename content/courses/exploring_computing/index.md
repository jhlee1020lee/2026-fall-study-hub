아래 순서로 단원을 읽으세요. 각 단원에서 연결된 원자료·수업 기록과 연습문제를 확인할 수 있습니다.

## 단원 목차

1. **Graph 모델과 경로 연결의 동기** · [[courses/exploring_computing/units/graph-models-and-routing|한국어]]

   대상과 관계의 그래프 표현, 동시 경로의 양립성과 실제 배선 제약을 구분한다.

2. **제한된 인스턴스와 fixed parameter 관점** · [[courses/exploring_computing/units/restricted-instances-and-parameters|한국어]]

   공간 제한, 입력 크기와 요구 수, 알고리즘의 존재·절차·비용을 나누어 판단한다.

3. **Clique의 연결 자유도와 interface 환원** · [[courses/exploring_computing/units/clique-interfaces-and-reduction|한국어]]

   클리크의 접근 조건과 현재 요구의 답을 보존하는 정점 삭제·반복 환원을 설명한다.

4. **반례로 다듬는 Graph 구조의 직관** · [[courses/exploring_computing/units/structural-intuition-and-counterexamples|한국어]]

   추가 정점·곡면·국소 예외와 반례를 통해 구조 설명의 조건을 다듬는다.

5. **구조적 도구와 응용·성능 평가** · [[courses/exploring_computing/units/theory-models-and-applications|한국어]]

   응용과 일반 구조 도구, 가중치 계산, 그래프 연구 질문과 성능 근거를 비교한다.

6. **이론 연구의 이해·설명·유용성** · [[courses/exploring_computing/units/research-understanding-and-utility|한국어]]

   이해와 설명의 기여, 연구 유용성의 근거, 직접 영감과 활동 전환을 구별한다.

7. **AI 가설·검증·연구 기여 논의** · [[courses/exploring_computing/units/ai-hypotheses-and-authorship|한국어]]

   AI의 후보 생성과 검증, 미래 역할·자원 가설, 기여 공개와 실제 심사 요건을 구분한다.
