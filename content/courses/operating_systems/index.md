# 운영체제 (Operating Systems)

2026학년도 2학기 활성 과목입니다. eTL 과목은 운영체제 (001)입니다.

## 강의노트

아직 승인된 강의노트가 없습니다.

## 개념 지도

강의가 추가되면 관련 개념이 자동으로 연결됩니다.
