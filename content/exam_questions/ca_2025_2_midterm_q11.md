<pre class="exam-question-text">11. (15 points) A program with 200 billion instructions runs on Machine A, which has a 2.5 GHz clock, in 10 seconds. You are designing Machine B to run the same program in 6 seconds.

(a) (5 pts) What is the Cycles Per Instruction (CPI) for the program on Machine A?

(b) (5 pts) Machine B will have a 3.0 GHz clock. What CPI must Machine B achieve to run the program in 6 seconds?

(c) (5 pts) You are considering an enhancement for Machine B that only speeds up floating-point (FP) instructions. FP instructions account for 20% of the total instructions. The CPI for non-FP instructions on Machine B is 1.25. Is it possible to achieve the target execution time of 6 seconds by only improving FP instructions? If yes, what is the minimum speedup factor for FP instructions needed? If no, explain why it is impossible.</pre>
