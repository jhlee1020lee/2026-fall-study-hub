<pre class="exam-question-text">Question 1. (5/0/-5 points for each correct/blank/wrong answer) True or False

(a) (¬q ∧ (p → q)) → ¬p is a tautology.

(b) (p → q) → (r → s) and (p → r) → (q → s) are logically equivalent.

(c) (p ∨ q ∨ ¬r) ∧ (p ∨ ¬q ∨ ¬s) ∧ (p ∨ ¬r ∨ ¬s) ∧ (¬p ∨ ¬q ∨ ¬s) ∧ (p ∨ q ∨ ¬s) is satisfiable.

(d) ∃x(x &gt; 0 → x³ &lt; 0) is true where the domain is ℝ.

(e) If ∃x∀yP(x, y) is true, then ∀y∃xP(x, y) is also true for any propositional function P(x, y).

(f) (A − B) − (C − D) = (A − C) − (B − D) for any sets A, B, C and D.

(g) If f(x) = Θ(g(x)), then log f(x) − log g(x) = O(1) where f, g are functions from the set of real numbers to the set of positive real numbers.

(h) If P = NP, then any NPC problem can be solved in a polynomial time.

(i) Let m &gt; 1 be a positive integers and a, b, c be integers. If ac ≡ bc (mod m), then a ≡ b (mod m).

(j) In the RSA cryptosystem, it is insecure if the encryption key is published.</pre>
